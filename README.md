# Portfolio

Personal portfolio site for [David Anukam](https://github.com/davidanukam)
> CS + SWE student at Western University, full-stack developer, and simulation engineer in training.

Built with **Next.js**, **React**, **TypeScript**, **Tailwind CSS**, and **Material UI**.

## Features

- **About Me**: bio, skills, and social links (GitHub, YouTube, Discord, LinkedIn, email, phone)
- **Experience**: work history cards with tech tags, timeline support, and external links where applicable
- **Projects**: sortable project cards with descriptions, tech tags, screenshot previews, and live/repo links
- **Other**: YouTube channel highlight
- **Responsive layout**: sticky sidebar on desktop, collapsible nav on mobile
- **Project screenshots**: 16:9 thumbnails with dashed borders (click to open a full-size lightbox preview)
- **Resume**: downloadable PDF from `public/David_s_CS_Resume.pdf`

## Tech Stack

| Layer | Technologies |
|-------|--------------|
| Framework | Next.js 16 (App Router), React 19, TypeScript |
| Styling | Tailwind CSS 4, custom CSS variables (`globals.css`) |
| UI | Material UI icons, JetBrains Mono + Geist fonts |
| Tooling | ESLint, Turbopack |
